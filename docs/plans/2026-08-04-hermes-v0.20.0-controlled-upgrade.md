## 全局约束

- 目标版本固定为 tag `v2026.8.3`，不得使用漂移的 `main` 或 `latest`。
- 不覆盖 canonical 当前未提交改动，不在旧 shared install 内运行原地 update/reset/stash。
- 不读取、打印或写入文档的对象：API key、OAuth token、cookie、session 正文、memory 正文、用户业务正文。
- runtime、Profile、数据库、日志和凭据继续留在 `~/.hermes`，不得写入 canonical source。
- 生产切换前必须保存代码 patch、Git bundle、每个 Profile 的 quick backup、LaunchAgent plist 与当前 PID/版本清单。
- 配置迁移必须先在临时 HERMES_HOME 验证；真实迁移必须逐 Profile 执行。
- 若候选测试失败、配置迁移不可逆、Gateway 不能连接、Cron 不能列出、关键健康检查失败或新日志出现持续异常，立即停止后续 Profile 切换并回滚已切换 Profile。
- 不触发真实发布、群发、付费动作或业务 Cron；验证仅使用 CLI、状态回读、隔离 smoke 和已有健康端点。
